# python-svg-editor

Editor for SVG files. SVG image is displayed on the right and its source is displayed on the left. When the source is saved the image updates.

## Screenshot

![screenshot](https://github.com/Gestalte/python-svg-editor/blob/Master/screenshot.PNG?raw=true)

## How to build

Using [PyInstaller](https://pyinstaller.org/en/stable/): `pyinstaller --onefile --noconsole --icon=svg-icon.ico python-svg-editor.py`
